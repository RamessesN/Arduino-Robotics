\subsection{Data Acquisition}
Raw data is collected via Arduino IDE with triplicate measurements per group~\eqref{lst:distance-detect}.
After selecting the obstacle, measurements are taken at intervals of 40 centimeters
within a range of 0 to 400 centimeters from the obstacle.
The measurement angles span from 0 to 180 degrees,
with the direction directly in front of the vehicle's nose defined as 90 degrees.
The formulas~\eqref{eq:distance} used are as follows:

\begin{equation}
  Distance = Velocity \times Time
  \label{eq:distance}
\end{equation}

In the experimental environment, where the air is dry and the temperature is 20 degrees Celsius,
the speed of sound is approximately 343 meters per second, which is equivalent to 34,300 centimeters per second.
Since the ultrasonic wave travels twice the distance from the transmitter to the target and back to the receiver,
the actual distance measurement is related to the time difference as follows:
\textit{a distance of 1 centimeter corresponds to a time difference of 58.3 microseconds}, which
can be approximated to 58 microseconds for simplified calculations.

\subsection{Extraction and Production}
Several Python scripts are used in this step.

Firstly, We design a simple Python program \textit{DataExtraction.py}~\eqref{lst:data-extraction}.
The Python code is based on \textit{pandas}, and
it extracts those raw data and automatedly store them into an \textit{Excel} file.
Additionally, there are three pieces of values.
We make another Python script \textit{DataAverage.py}~\eqref{lst:data-average} to calculate the average value.
